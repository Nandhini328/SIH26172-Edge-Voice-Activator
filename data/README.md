# Data

Large datasets and binary exports are intentionally not committed directly to the repository yet.

Current local analysis assets include Edge Impulse MFE testing/training arrays, labels and exported Float32/INT8 model artifacts.

For reproducibility, record:

- dataset/project name and version
- class order
- feature extraction settings
- train/validation/test split
- model export version
- quantization settings
- SHA-256 hashes of large model/data artifacts

Private or personally identifiable audio recordings must not be uploaded to this public repository.
